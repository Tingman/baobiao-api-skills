# baobiao-api-skills
世舶科技招投标数据 API 场景 Skill 扩展包，覆盖招标项目查询、招标公告查询、中标项目查询、中标结果查询、项目详情与附件获取、政府采购意向、合同公告、拟在建项目查询等高频需求；支持企业研究、企业画像、投标参考、项目分析、竞争对手监测、商机挖掘和采购客户分析。日更新招投标数据 30 万+，帮助用户快速查标、找项目、看中标、做企业研究，提升投标决策与市场拓展效率。

**直接 API 基础地址**：`https://gate.gov-bid.com/outer-gateway`

**请求方式**：除 MCP 外，本文接口均使用 UTF-8 JSON `POST` 请求。

```text
POST https://gate.gov-bid.com/outer-gateway/bid/{接口名}?key={API_KEY}
Content-Type: application/json
```
